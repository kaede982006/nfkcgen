# nfkcgen

**nfkcgen 1.0**은 크고 긴 TTS 출력을 탐색하기 위한 GTK4 연구용 문자열 생성기입니다.
문자열만 생성하며 TTS 호출, 음성 재생, 시스템 볼륨 조절은 하지 않습니다.

## 사용

1. 기존 고전/신규 × 1~4류 중 유형을 고르고 목표 길이(20~120 코드 포인트)를 정합니다.
   기본값은 신규 1류, 120자입니다. 2·3류는 일반 문장 한 줄, 4류는 두 줄 이상을 입력합니다.
2. **생성 → 복사**로 후보 원문을 얻어 연구 대상 TTS에서 시험합니다.
3. 동일한 TTS·음성·속도·녹음 게인에서 측정한 LUFS와 발화 지속 시간을 입력하고
   **현재 후보에 실측 반영**을 누릅니다. 전체 영상 길이나 피크 dBFS를 입력하지 않습니다.
   실패는 0초로 기록합니다. 같은 후보를 재시도했다면 매 시도의 측정치를 각각 입력합니다.
4. **생성**을 누르면 실측 우수 후보의 외부 문자 순서를 바탕으로 각 위치를 20% 확률로
   다시 추출합니다. 일반 문장은 유지됩니다. 매 네 번째 후보는 독립 추출해 탐색을 계속합니다.
   성공한 측정이 없으면 모두 독립 추출합니다. 변이율은 검증된 최적값이 아닌 초기 휴리스틱입니다.
5. **우수 후보 복사**로 현재까지 가장 높은 평균 탐색 점수의 문자열을 가져옵니다.

측정 기록은 **이번 실행의 메모리 안에만** 유지됩니다. 유형·길이·일반 문장을 바꾸고
생성하면 비교 조건이 달라지므로 초기화됩니다. 앱 종료 전에 필요한 후보를 복사하세요.
같은 TTS 설정의 반복 측정을 비교해야 하며, TTS 설정을 바꾸면 앱을 다시 실행하세요.

## 평가 방법

성공한 시도는 `duration_seconds * 10^(LUFS / 10)`으로 평가하고, 실패는 0으로 평가합니다.
후보별 모든 시도 값의 산술평균을 비교합니다. 화면의 점수는 그 평균의 `10*log10`입니다.
따라서 실패가 누적되면 평균 점수가 낮아지고, 음량 또는 지속 시간이 커지면 점수가 올라갑니다.

이 점수는 **음량과 지속 시간을 함께 다루기 위한 탐색 목적함수**이며, 물리적 음향 노출량이나
청감·불쾌감의 표준 척도가 아닙니다. LUFS의 게이팅 때문에 실제 신호 에너지와 같지 않습니다.
고주파 에너지 비중은 평균 음량과 다를 수 있으며, NFKC 확장 길이도 발화 시간과 같지 않습니다.
현재 문자 집합과 확장 가중치는 초기 탐색에만 사용합니다. 특정 문자가 반드시 크거나 긴
출력을 내는 것으로 검증된 것은 아닙니다. 여러 후보에 동일한 횟수의 반복 측정을 권장합니다.

`build_candidate()`는 같은 시드·부모 외부 문자열·설정·문자 집합으로 결과를 재현할 수 있습니다.
GUI는 새 시드를 매번 만들고 표시합니다. 시드만으로 변이 후보를 재현할 수는 없습니다.

## 빌드·검증

Linux, C 컴파일러, make, pkg-config, GTK4 개발 파일(4.12 이상)이 필요합니다.

```sh
make
make check
make check-ui  # Xvfb, dbus-run-session 필요
./nfkcgen
./nfkcgen --version
sudo make install PREFIX=/usr/local
```

**한글 입력:** GTK4 앱은 IBus GTK4 입력 모듈(`ibus-gtk4`)이 없으면 IBus 한글 엔진을 쓰지 못하고
영문만 입력됩니다. Debian·Ubuntu는 `sudo apt install ibus-gtk4`, Fedora는 `sudo dnf install ibus-gtk4`
후 앱을 다시 실행하세요. DEB/RPM 패키지는 이 모듈을 권장 의존성으로 함께 설치합니다.

DEB/RPM은 x86_64 Linux용이며 빌드 환경의 라이브러리 ABI 요구사항을 따릅니다.
이 릴리스는 사용자가 지정한 연구 버전 **1.0**이며 배포 태그는 `v1.0.0`입니다.
구버전 `1.0`, `1.1`, `1.1.0`의 릴리스·태그·배포물은 삭제되었습니다. 기존 1.1 패키지에서 설치하면
패키지 관리자는 버전 하향으로 취급할 수 있습니다.

## 범위

TTS 엔진 연동, 녹음 자동 분석, 세션 저장·불러오기는 포함하지 않습니다.
이 버전의 실제 대상 TTS 개선 효과는 별도의 반복 실험으로 확인해야 합니다.
프로그램 이름·실행 파일·창 제목·데스크톱 항목은 모두 `nfkcgen`입니다.
